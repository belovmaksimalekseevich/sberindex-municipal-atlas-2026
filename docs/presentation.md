## 3. Близость учитывает уровень и состав расходов

L — логарифм Total; h — контраст геометрического среднего пяти категорий с Total; R — четыре координаты относительного состава (HelmertCLR).

d² = 0,5·dL²/sL² + 0,25·dh²/sh² + 0,25·‖dR‖²/sR²

| Этап | Правило |
| --- | --- |
| Признаки | Уровень расходов, контраст пяти категорий с Total, относительная форма |
| Граф NCut | Union kNN, k = 15 с точными равенствами; w = exp(−d²/2), σ = 1 |
| Общая оценочная сеть | Радиус 1,5 в том же пространстве X6 |
| Сеть экрана | Пять сильнейших связей с равенствами; точное подмножество графа |

Точные определения: L = ln Total; h = ln(GM(c)/Total); R = H·CLR/√5. GM(c) — геометрическое среднее пяти категорий. h не является бухгалтерской долей их суммы. X6 содержит L, h и четыре координаты R. Для S_Dbw применяется эквивалентное по расстояниям представление Y7.

Источники: [S02: Методология признаков графов и шести индексов](https://github.com/belovmaksimalekseevich/sberindex-municipal-atlas-2026/blob/main/docs/evidence/S02.md).

## 14. Атлас связывает карту, сеть и паспорт

Выбор модели и месяца обновляет группы, показатели, сеть и паспорт выбранной территории. Пропуски и неизвестная география показаны отдельно.

Аналоги Екатеринбурга

По Total: Красноярск, Тюмень, Нижний Новгород.  
По контексту: Пермский городской округ, Нижний Новгород, Тюмень.

На экране показана часть рёбер. Проекция расходов не является географической картой.

Пример из §10 отчёта: Екатеринбург, ID 1971. Заранее заданы фильтры: городской округ, население от половины до удвоенного, Total в пределах 10%, вне Москвы и Санкт-Петербурга. Получены пять кандидатов. Первые два контекстных аналога относятся к другой NCut10-группе и были бы потеряны при жёстком фильтре по кластеру. Разный порядок аналогов показывает, почему расходное сходство нужно дополнять проверкой исходных внешних показателей.

Иллюстрация на слайде показывает действующий интерфейс сети; это не отдельный снимок выбранных аналогов Екатеринбурга.

## 15. Проверка сохранённых данных отделена от пересчёта

Переносимый научный комплект включает код, входы, параметры и результаты. Большой рабочий архив ВМ для чтения не нужен.

| Действие | Результат и граница |
| --- | --- |
| python -B research/release.py verify<br>из корня репозитория | SHA-256 и 532 сохранённых разбиения; нового обучения нет |
| Полный контроль на ВМ | 504 месячных + 28 контекстных разбиений; принят исходный вычислительный r03 |
| Текущая редакция r04 | Те же ядра и результаты; исправлена защита пути CSV-экспорта и документация |
| Новый полный запуск | Отдельная команда, Linux, зафиксированные зависимости и новый каталог результата |

Полный повтор r04 в чистой внешней упаковке не выполнялся. Побайтная проверка и запуск читателя подтверждены отдельно.

Команда выполняется из корня клонированного репозитория:

```console
python -B research/release.py verify
```
