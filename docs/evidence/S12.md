# Исправленный тест поиска аналогов r02

**Основной результат: добавочная польза кластерных ограничений не подтверждена.** На правильной опоре **1 445 территорий вне Москвы/Санкт-Петербурга** ни один жёсткий или мягкий способ NCut/SSE не улучшил одновременно прямой поиск по расходам и прямой контекст без зарплаты. Общая опора всех восьми способов — **1 419 ID / 67 регионов**.

Этот результат заменяет ошибочно суженный проход r01 на 1 388 ID. Первоначальные правила семи способов поиска, медианного контроля, целевого показателя, числа аналогов и усреднения не менялись. Новых кластеризаций и SSH не было. Протокол — [PROTOCOL.json](PROTOCOL.json); явное исправление входа до r02 — [AMENDMENT_2.json](../AMENDMENT_2.json).

## Исправление источника и история

Первичные метаданные СберИндекса на страницах 1–2 определяют полуоткрытый интервал: **year_from ≤ year < year_to**. Предыдущий новый readback ошибочно включал конечный год и создал 57 ложных неоднозначностей в контекстном ядре. Их исключение в r01 было ошибкой подготовки, а не свойством данных; этот проход нельзя использовать как основную строгую проверку или как доказательство реальной неопределённости реформ.

В r02 все **1 666 исходных контекстных ID** проверены непосредственно по первичному XLSX и исправленному реестру. У каждого ровно одна активная строка 2024; её номер, тип, имя, регион и ОКТМО **совпали с исходным core_ID_context.csv**. Изменений полей не потребовалось. Проверка записана в [TYPE_BINDING.json](TYPE_BINDING.json). Исправленный реестр: `readback/corrected_r01/TYPE_REGISTRY.json`, SHA256 `926fff983ef4ae7274e91cb5fcb001062e42de85c040e4971d72e6473b586c78`.

Первый r00 сохранён в `../initial_conditional_types_r00/`; ошибочный r01 — в `../historical_strict_exclusion_r01/`. После исправления **все выбранные ID аналогов и весь PER_QUERY.csv побайтно совпали с первым r00**. Таким образом, исходное вычисление получило корректную проверку типов, а отрицательный вывод не оказался следствием ошибочного исключения 57 ID. История и сравнение на одинаковых запросах: [HISTORY_COMPARISON.json](HISTORY_COMPARISON.json).

## Опора и протокол

Из 1 666 ID исключены только **221** территории Москвы/Санкт-Петербурга. Все необходимые численные и метаданные поля остальных **1 445 ID / 67 регионов** допустимы: 289 городских округов, 859 муниципальных районов, 297 муниципальных округов.

Запрос — территория с декабрьским расходным профилем 2024; удерживаемое поле — средняя месячная зарплата охваченных организаций за весь 2024. Кандидаты должны иметь **тот же точный supplier_type и другой регион**. Свой регион полностью исключается из выбора. Пять аналогов дают среднее log зарплат; медианный контроль — медиану log зарплат всех допустимых кандидатов. Рублёвый прогноз — экспонента, без корректировки.

Семь правил: ближайшие по log Total; ближайшие по полному замороженному расходному X; ближайшие по четырём контекстным координатам без зарплаты; hard NCut/SSE только внутри своей группы; soft NCut/SSE — до трёх соседей своей группы и дополнение до пяти ближайшими по X. При равенстве расстояний используется числовой ID. Контекст: log населения, log1p market_access, log1p работников/жителей, arcsin sqrt доли образования; IQR вычисляется только на кандидатах данного запроса. Нулевых IQR не обнаружено. Годовые context6-метки **не читаются**: они обучены с зарплатой и внесли бы утечку.

## Сравнение на одинаковых 1 419 запросах

Основная ошибка — MAE log зарплаты, сначала средняя внутри региона, затем равный вес 67 регионов. Меньше — лучше. Это не процентная ошибка дохода человека. Все ошибки таблицы используют одни и те же запросы; последний столбец отдельно показывает доступность на всей опоре 1 445.

|---|---:|---:|---:|---:|
| Только Total | 0,172234 | 13 411 | +11,55% | 1 445 |
| Полный расходный профиль X | 0,154407 | 11 894 | контроль | 1 445 |
| Прямой контекст без зарплаты | **0,151203** | **11 361** | −2,08% | 1 445 |

Hard NCut не имеет пяти аналогов своей группы для **14** запросов, hard SSE — для **13**; один запрос общий. Основная опора исключает объединение этих потерь — 26 ID. Охват: [COVERAGE.json](COVERAGE.json), причины по каждому запросу: [PER_QUERY.csv](PER_QUERY.csv).

По фиксированному условию положительного результата кластерный способ должен улучшить **оба** сильных контроля. Ни один условие не выполнил. По сравнению с контекстом ошибка NCut hard выше на **5,48%**, SSE hard — **4,03%**, NCut soft — **3,16%**, SSE soft — **2,73%**.

Полный расходный профиль уменьшил основную ошибку против одного Total на **10,35%**, прямой контекст — на **12,21%**. Это узкое наблюдение в данном протоколе; оно поддерживает использование дополнительных признаков при поиске, но не доказывает добавку кластерных меток. Независимая статистическая значимость малых различий не установлена.

## Предусмотренные проверки опоры

На общей опоре шести способов без hard (**1 445 ID / 67 регионов**) log MAE: полный X **0,155046**, прямой контекст **0,152375**, NCut soft **0,156372**, SSE soft **0,155567**. Мягкие способы также не выигрывают оба контроля. Отдельные тройки hard/полный X/контекст на доступных каждому hard запросах дают тот же отрицательный вывод. Все панели доступны в `SUMMARY.json:/panels`, значения каждого региона — [PER_REGION.csv](PER_REGION.csv).

Ошибочное исключение 57 ID меняло порядок двух прямых методов, но этот r01 теперь имеет только исторический статус, а не статус допустимой альтернативной опоры. Не используем последствия ошибки как научный аргумент о реальной чувствительности исходных данных. Подлинные предусмотренные проверки опоры — общий набор всех восьми способов, общая опора шести без hard и отдельные сопоставимые тройки hard.

## Практическое решение

**В этой задаче не применять кластер как обязательный фильтр аналогов.** Hard увеличил ошибку и сократил охват; мягкая квота также не подтвердила улучшение. Для аналитической процедуры доступны прямое расходное и отдельное контекстное ранжирование с явным назначением сравнения. Кластеры остаются способом обозрения профилей и навигации; они не получили основания объявляться более точным способом восстановления зарплаты.

Исследовательский вопрос о добавке этих фиксированных кластерных ограничений закрыт результатом **«не подтверждено»**. Параметры не перенастраиваются ради положительного ответа. Три подготовленных практических сценария показывают выполненные действия аналитика и ограничения меток, но не подменяют отрицательный количественный тест.

## Ограничения

Зарплата охваченных организаций без малого предпринимательства не равна доходам жителей; работники/жители — не занятость жителей, доля образования — не бюджетная доля. Контекстные показатели могут иметь общий upstream с зарплатной статистикой. Непосредственная зарплата исключена из расстояний, однако полная независимость источников и модельных расходов поставщика неизвестна.

Это ретроспективное восстановление годового поля, не прогноз будущего. Национальные метки и нормировка заморожены на полной панели; исключение региона из кандидатов не означает, что весь кластерный pipeline обучался только на других регионах. Предыдущие зарплатные тесты и примеры уже просмотрены; новый результат не является нетронутым holdout. Одинаковый тип и опубликованное годовое правило не удостоверяют все физические границы. ROI, экономия времени пользователя, причинность и функции экономики не измерены.

## Проверка и воспроизведение

[QA.json](QA.json): подтверждены отсутствие зарплаты/context6 в контракте поиска; неизменность всех выбранных ID при перестановке зарплаты и изменении её столбца `X_raw`; одинаковый тип и другой регион у каждого аналога; пять уникальных аналогов без самого запроса; пересчёт всех прогнозов из ID; пересчёт всех общих опор и региональных агрегатов из CSV; неизменность входных SHA. [FINAL_RECEIPT.json](FINAL_RECEIPT.json) подтверждает идентичный повтор девяти основных артефактов и хранит их хэши. Независимая приёмка оформляется отдельно.

Воспроизведение из этой папки: `python -B run_test.py`, затем `python -B finalize_test.py`. Используются Python, NumPy и openpyxl; версии основных зависимостей фиксирует `RUN_RECEIPT.json`. Все источники и SHA — [SOURCE_HASHES.json](SOURCE_HASHES.json), выборы — [NEIGHBORS.json](NEIGHBORS.json), отдельные ошибки — [PER_QUERY.csv](PER_QUERY.csv). Расчёт занимает секунды на одном потоке BLAS, без нового обучения моделей.
