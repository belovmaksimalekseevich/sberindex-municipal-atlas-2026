# Актуальный состав контекстного комплекта

Текущая задача — отдельная ретроспективная сетка 2024 года: 1666 принятых ID, 69 регионов, варианты `context6` и `spending2`, Ward/KMeans, K=4/6/8/10/12/16/20. Выбранный годовой контекст — context6/KMeans/K6. Это отдельное пространство; оно не является национальной шестикластерной версией месячной типологии.

Файл `science/context/input/SEMANTICS.md` перенесён без изменения как **историческая семантическая справка исходного входа**. Его упоминания K2, прототипа, директории `admission_evidence` и полного реестра документов не описывают актуальный состав этой сокращённой поставки. Файлы `PLAN.json`, `CODE_POLICY.json`, исходные `SOURCE_BINDING.json` также сохраняют исторические операционные записи. Актуальный состав определяют корневой `PACKAGE_MANIFEST.json`, README, эта карта и `config/release.json`.

| Файл в поставке | Назначение |
|---|---|
| `science/context/input/context2024.npz` | Точный запечатанный вход: массивы, ID, регионы, значения и месячные расходы |
| `science/context/input/core_ID_context.csv` | Метаданные ID для наблюдаемых представителей и профилей |
| `science/context/input/schema.json` | Фактические поля/формы массивов, 1666 ID, 69 регионов, порядок признаков |
| `science/context/input/ADMISSION_CORRECTION.json` | Историческое описание исправленного правила допуска |
| `science/context/input/SCIENCE_PLAN.json`, `source_semantics.json`, `SOURCE_BINDING.json` | Замороженные научные определения и исходная привязка источников |
| `science/context/model.py`, `preprocessing.py`, `runner.py` | Неизменённые научная модель, преобразования и worker |
| `science/context/PLAN.json`, `TASKS.json` | Неизменённые настройки и 28 задач полного входа |
| `science/context/CODE_ORIGIN.json`, `CODE_MANIFEST.json`, `CODE_POLICY.json` | Происхождение и исторические условия замороженного кода |
| `provenance/context_original_manifest.json` | Полный состав исходного пакета до сокращения |
| `science/context/PACKAGE_MANIFEST.json` | Проверяемый состав сохранённых файлов текущей копии |
| `saved/context/` | Все 28 принятых результатов: метки, метрики, профили и их исходные SHA-привязки |

`input/admission_evidence/`, первоначальные сырьевые строки, подготовительные скрипты, исторические реестры, wheels-списки и кеши **в эту копию не включены**. Причины указаны в `provenance/FILE_MAP.json`, SHA реально использованных источников — в `provenance/SOURCE_INDEX.json`; оригинальные члены перечислены в `provenance/context_original_manifest.json`. Эти ссылки обеспечивают происхождение, но не означают, что исключённые файлы доступны внутри кандидата. Повторная проверка всей исходной процедуры допуска требует отдельно восстановить оригинальный запечатанный пакет по его источнику и SHA.

Сокращение не меняет фактический вычислительный вход. Sealed preflight текущей копии проверяет его SHA, массивы, ID, число регионов и версии библиотек; оно не повторяет всю историческую проверку допуска. Управление detached-потомками принято независимой проверкой на реальном Linux; точная привязка доступна в `config/release.json`. Полный научный контрольный расчёт окончательного комплекта остаётся отдельной предстоящей проверкой.
