# Сходство муниципалитетов: научная поставка

Комплект содержит код, входные данные и сохранённые результаты кластеризации муниципалитетов по модельным средним безналичным расходам жителей за 2023-2024 годы. Для чтения и проверки результатов достаточно Python 3.11 или новее. Другие файлы проекта скачивать не требуется.

В каталоге есть **532 разбиения**: 504 месячных и 28 годовых контекстных. Месячная сетка охватывает 24 месяца, методы NCut, SSE и Ward, K из набора 4, 6, 8, 10, 12, 16, 20. Каталог содержит 2190 ID и 50521 наблюдаемый ID-месяц. Отсутствие публикации сохранено как пропуск.

Текущие роли моделей:

- NCut10: подробное описательное представление сети и расходных профилей.
- SSE10: сравнение метода при том же числе групп и той же опоре.
- SSE6: самостоятельный укрупнённый взгляд. Его более высокая средняя устойчивость в июне и декабре 2024 сопровождается потерей отдельных различий между подробными группами.

Годовой context6 с KMeans и шестью группами рассчитан отдельно на 1666 территориях в 69 регионах. В нём используется внешний контекст 2024 года; он не равен месячному SSE6 и не служит независимой проверкой расходной типологии. Подробное решение и ограничения сохранены в [MODEL_DECISION.md](evidence/MODEL_DECISION.md), таблицы сравнения в [MODEL_COMPARISON.json](evidence/MODEL_COMPARISON.json).

## Быстрая проверка

Из распакованного каталога выполните:

```text
python -B release.py verify
```

Команда проверяет состав и SHA-256 поставки, затем все 532 сохранённых разбиения: уникальность ячеек, ID, размеры групп, индивидуальные SW и статусы метрик. Ожидаемый результат: `passed: true`, `new_fits: 0`, 504 национальных и 28 контекстных разбиений. Для месячных результатов S_Dbw определён в 175 случаях; в 329 сохранены `null` и причина неопределённости. Быстрая проверка не повторяет обучение.

Просмотр и CSV-экспорт доступны через команды читателя `code/typology.py`, описанные в [инструкции читателя](code/README.md). Все создаваемые файлы должны лежать вне распакованной поставки. Не создавайте внутри неё виртуальное окружение или кеш Python: состав файлов проверяется строго.

## Полный пересчёт

Полный запуск требует Linux, Python 3.11, доступных CPU0 и CPU7 и точных версий зависимостей. Установите окружение вне поставки:

```text
python3.11 -m venv ../sberindex-venv
../sberindex-venv/bin/python -m pip install -r code/requirements-compute.txt
```

Одна команда запускает отдельный полный пересчёт. Папка результата должна быть новой и находиться вне поставки:

```text
../sberindex-venv/bin/python -B release.py full-fit --out ../sberindex-full-result --allow-real-fitting --exclusive-cpus-confirmed
```

Флаги явно разрешают обучение и подтверждают выделение CPU для расчёта. Контроллер выполняет 26 шагов последовательно; январский пилот предшествует остальным январским K. Автоматических повторов и продолжения неполной папки нет. Если процесс выходит за пределы времени, памяти или свободного диска, запуск останавливается с квитанцией.

| Ресурс | Настройка сохранённого контроллера |
|---|---:|
| Одновременные вычислительные процессы / потоки библиотек | 1 / 1 |
| CPU месячных / контекстных задач | 0 / 7 |
| Лимит месячной задачи | 1800 с |
| Лимит контекстной серии | 600 с |
| Общая вычислительная очередь | 18000 с |
| Измеряемый RSS дерева worker | 4 GiB |
| Минимум свободного диска перед задачей | 12 GiB |
| Рекомендуемое свободное место после установки окружения | 32 GiB |

Рекомендуется машина с 8 vCPU и 16 GiB RAM или больше, где доступны назначенные CPU. Это рекомендация для запуска сохранённой конфигурации, а не гарантия времени. На использованной ВМ принятый контроль исходной r03 занял 9416,33 с до завершения архива. Для нового запуска следует выделить до пяти часов вычислений и отдельно час на проверку, упаковку и закрытие процессов. Этот последний час не выполняется автоматически командой `full-fit`.

Статус завершённой очереди означает, что задачи выдали результаты. После нового полного запуска отдельно проверяют полноту 504 и 28 разбиений, сравнивают метки и численные статусы с сохранённой версией, проверяют отсутствие процессов. Архив старого запуска не заменяет эти проверки нового результата.

## Что сохранено неизменным

Каталог `code/` побайтно повторяет принятую редакцию читателя r04. Её научные ядра, входы, параметры, compute- и owner-модули совпадают с использованной в полном контроле r03. Изменения r04 касаются защиты пути CSV-экспорта и документов. Отдельный полный расчёт r04 и этой внешней упаковки не выполнялся.

Исторические комментарии и квитанции внутри `code/` сохранены для происхождения. Упоминания рабочих путей в них не являются инструкциями и не нужны для запуска. Текущий порядок запуска задан этим README. Исходный manifest r04 сохранён; внешний `PACKAGE_MANIFEST.json` дополнительно связывает весь комплект. [SOURCE_BINDINGS.json](evidence/SOURCE_BINDINGS.json) связывает шесть защищённых источников подготовки.

Для основной геометрии используются шесть координат X6: уровень L, контраст h и четыре координаты HelmertCLR4. Для S_Dbw сохранено эквивалентное по попарным расстояниям семикоординатное представление Y7. Число исходных расходных показателей, число координат представления и число групп обозначают разные вещи.

## Состав

- `code/`: читатель, запуск полного расчёта, научный код и конфигурации JSON.
- `code/science/`: необходимые входные NPZ/CSV и неизменённые планы.
- `code/saved/`: 532 компактных результата с ID, группами, индивидуальным SW, метриками и профилями.
- `code/tables/`: сводки методов, K, стартов и доступности метрик.
- `code/provenance/` и `evidence/`: исходные привязки, принятые квитанции и решение о ролях моделей.
- `release.py` и `PACKAGE_MANIFEST.json`: проверка переносимого комплекта и явный запуск полного пересчёта.

Большие матрицы расстояний, полный архив ВМ и рабочие журналы оптимизации не включены: они не требуются для быстрого чтения и для нового расчёта. Входные данные включены в комплект, дополнительных ссылок на крупные файлы для запуска нет. Версии Python-библиотек устанавливаются отдельно из реестра пакетов.

Код и данные предназначены для представления результата конкурса. Источники данных и сторонние библиотеки сохраняют свои условия использования и авторство; новая лицензия на них не назначается. [AUTHORS.md](code/AUTHORS.md) описывает автора коммитов, а не состав конкурсной команды. Сведения об участниках и согласия для заявки заполняются отдельно.

Описательные группы не устанавливают универсальные функции экономик или причины изменений. Сеть отражает сходство расходов, а не денежные потоки. Предшествующий тест на 1419 ID в 67 регионах не подтвердил пользу обязательного или мягкого фильтра K10 при поиске аналогов; этот вывод не является тестом SSE6. Для применения нужны сравнение исходных профилей, учёт покрытия и содержательная проверка выбранных территорий.
